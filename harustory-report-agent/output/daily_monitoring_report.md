## 부록. 반복 작성 및 자동화 기준

이 부록은 템플릿 설정용이다. 매일 배포하는 리포트에는 1~4번 영역만 포함한다.

### A. 지표 연결표

| 영역 | 기본 점검 지표 | 변화 발생 시 확인할 상세 지표 |
|---|---|---|
| 유저 | DAU, 신규 유저 수 | 전체 이벤트 수, 진입·가입 이벤트 수집 여부 |
| 페이지 | 총 PV, 총 UV, PV/UV | 탭별 PV·UV |
| 미션·퍼널 | 미션 완료 수, 미션 UV, 출석 Day 1 UV, 지정 핵심 퍼널 최종 전환율 | 미션별 완료 수·UV, 유저당 완료 수, 퍼널 단계별 UV·전환율 |
| 매출 | 광고 매출, 콘텐츠 매출, 총매출 | 광고 카테고리·네트워크별 매출, 코인 결제·콘텐츠 이용 상세 |
| 리워드·환전 | 미션 지급 리워드(P), 실제 환전 지급액(원) | 건당·유저당 지급 P, 미션별 지급 P, 환전 상세 |

- 핵심 퍼널은 매일 확인할 기존 퍼널을 지정한다. 앱별 미운영 기능은 미적용으로 처리한다.
- 출석 Day 1 UV는 출석 시작 규모 확인용이다. 신규 가입자 수와 동일하게 해석하지 않는다.
- 리텐션, 7일 출석 완주율, 신규 유저 경로 등은 기본 일간 표에서 제외하고 필요 시 별도 분석한다.
- 동일일의 Day 7 UV ÷ Day 1 UV를 코호트 완주율로 사용하지 않는다. 완주율은 같은 시작 코호트의 추적 결과로 산출한다.
- 티켓 발급량은 현재 제공된 지표 목록에 없어 기본 표에서 제외했다. 일별 실제 발급량을 연결할 수 있으면 리워드·환전 영역에 별도 추가한다.
- 대시보드의 “순 영업 마진”을 사용할 경우 계산 범위를 명시한다. 총매출에서 실제 환전 지급액만 차감한 값은 다른 비용을 포함한 영업이익과 구분하고, 당일 환전에는 이전에 적립한 재화도 포함될 수 있음을 고려한다.
